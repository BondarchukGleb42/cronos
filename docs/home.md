# Главное меню 🪐 Cronos

Домашний чат — отдельная настоящая тема личного диалога с ботом. В ней закрепляется приветствие с кнопками. Имя **🪐 Cronos** сохраняется при работе модели и восстановлении контекста. Старые чаты, файлы, задания и тариф при создании домашней темы не меняются.

| Раздел | Поведение |
| --- | --- |
| ➕ Новый чат | Создаёт тему, отправляет в неё приветствие; рабочее название генерируется после первого вопроса и ответа |
| 💬 Мои чаты | Показывает рабочие темы по страницам; для переключения используется список тем Telegram |
| 📋 Мои задачи | Показывает активные задания, ближайший запуск в часовом поясе задания и периодичность |
| 💳 Мой тариф | Показывает текущий тариф, остаток и период; смена плана тестовая, без оплаты |
| 📖 Что могу | Короткий гайд по разговорам, инициативам, файлам, поиску и управлению обычным текстом |
| 🧠 Память | Показывает сохранённые общие сведения с пагинацией |
| ⚙️ Настройки | Показывает часовой пояс, стиль общения, текущий режим инициативы; позволяет включить или выключить инициативу и запросить полную очистку |

Разделы открываются без обращения к модели и редактируют текущее сообщение меню. Новая задача, изменение расписания, уточнение настроек и обычный разговор по-прежнему доступны свободным текстом. Полная очистка требует отдельного подтверждения, как описано в [privacy.md](privacy.md).

## Старт и возвращение в меню

`/start`, `/menu` и текст «меню» показывают главный экран. В сворачиваемой панели под полем ввода находятся «🤖 Модель», «🧠 Режим рассуждения» и «🗑 Удалить чат». Кнопок нового чата и главного меню в нижней панели нет. Новый чат создаётся из интерфейса Telegram, через `/new` или кнопку внутри домашнего меню. Под обычными ответами нет повторяющихся inline-кнопок. Если команда меню вызвана из другого чата, меню отправляется в домашнюю тему, а исходный чат получает подсказку, где его найти. Поддерживаются также `/chats`, `/tasks`, `/plans`, `/help`, `/memory`, `/settings`. Удаление из нижней панели требует подтверждения; контекстные кнопки меню и подтверждения остаются inline.

«Модель» открывает выбор GPT-5.6 Luna, Terra или Sol; Luna используется по умолчанию на всех тарифах. «Режим рассуждения» предлагает «Без рассуждения» (по умолчанию) и «Глубокое рассуждение». Оба выбора общие для пользователя и действуют на новые запросы во всех темах. Панели настроек не обращаются к AI-модели. Выбранная модель сохраняется для визуальных запросов и повторов после временного сбоя; поиск, генерация изображений и названия тем имеют отдельные маршруты.

Существующим пользователям с историей домашняя тема создаётся через сохраняемое событие миграции. Новым — непосредственно при `/start` либо отдельным заданием после первого обычного сообщения. Повторный запуск не создаёт вторую домашнюю тему или второе первоначальное приветствие. При полной очистке тема и её события удаляются; домашняя тема не восстанавливается, пока пользователь снова не начнёт взаимодействовать с ботом.

События миграции сначала недоступны обработчикам и активируются только новой версией Worker после запуска. Это исключает потерю заданий, пока прежняя версия ещё работает во время выкладки.

## Надёжность

Создание проходит под общей блокировкой работы пользователя и использует сохраняемое намерение с ключом поколения. Неопределённый ответ Telegram не приводит к автоматическому повторному созданию: пользователь получает явную кнопку повторной попытки. Метаданные домашней темы уникальны для пользователя. Удаление меняет поколение, поэтому старое задание инициализации не восстанавливает удалённую тему.

Меню отправляется через существующий outbox. Редактирование привязано к исходному сообщению только внутри домашней темы; при подтверждённом отсутствии сообщения оно создаётся заново в правильной теме. Устаревшие редактирования отменяются с учётом порядка входящих Telegram updates под блокировкой доставки. Переключение инициативы и тарифа идемпотентно для повторов одного callback. Ошибка закрепления не повторяет уже доставленное сообщение.

Инициатива включена по умолчанию для новых и существующих пользователей, если человек ранее явно её не отключил. Главное меню показывает текущий режим; выключить его можно в настройках или обычным сообщением. Повторное общее разрешение не требуется. Конкретные обращения сохраняются отдельно и выбираются по актуальному контексту: короткий check-in по обсуждённой теме или полезная подготовка в активном проекте. Действуют тихие часы, частота и бюджет. Явное отключение не отменяет заказанные пользователем напоминания и отчёты.

Открытие и переключение разделов не вызывает `editForumTopic`: переименование больше не используется для проверки существования home и не порождает служебную запись о смене названия при каждом возврате. Если реальная доставка вернула точное сообщение об отсутствии текущей домашней темы, Coordinator в одной транзакции завершает неудавшуюся доставку, отменяет ожидающие панели старой темы, меняет поколение home и ставит сохраняемое событие `home_init`. Worker создаёт новый home под обычной блокировкой работы пользователя. Устаревшая ошибка другой темы или старого home не заменяет текущий home; сетевые ошибки и ошибки прав не запускают восстановление. История и финансы сохраняются, подтверждённые части доставки не пересылаются в новую тему.

Новых сервисов, фоновых процессов и дополнительных ресурсов кластера нет. Все операции Telegram используют обязательный `TELEGRAM_PROXY`.

## Особенности Telegram

При разрешённом создании тем пользователем встроенный General отображается как общий обзор, а ввод сообщения может создать новую тему. Поэтому домашнее меню размещается в отдельной теме, созданной через [createForumTopic](https://core.telegram.org/bots/api#createforumtopic). [Поведение General в bot forums](https://core.telegram.org/api/forum#bot-forums).

[pinChatMessage](https://core.telegram.org/bots/api#pinchatmessage) закрепляет сообщение внутри темы. **Саму тему 🪐 Cronos пользователь закрепляет вручную в меню темы Telegram.** Bot API не позволяет закрепить её в списке; соответствующий MTProto-метод [messages.updatePinnedForumTopic](https://core.telegram.org/method/messages.updatePinnedForumTopic) доступен только пользовательским аккаунтам. Закреплённое приветствие не считается закреплённой темой. Принудительно открыть тему на экране пользователя бот тоже не может. Ссылки на конкретную тему личного чата бот не выдумывает. Если Topics Mode недоступен, меню показывается в обычном личном чате.


## Персональное продолжение

Главный экран читает актуальные данные владельца: до трёх активных проектов со следующими шагами, до трёх недавних текущих версий файлов и число активных заданий. «Мои проекты» открывает список; карточка позволяет создать новый чат с подключённым контекстом или скрыть предложение до изменения проекта. Скрытые предложения можно вернуть. «Убери подсказки из меню» меняет `home_suggestions` через обычный диалог.

Обязательной анкеты нет. Первый запрос обрабатывается сразу, детали уточняются по необходимости. Устаревшая кнопка заново проверяет владельца и доступность проекта/результата; она не восстанавливает очищенный контекст. /projects открывает проекты, остальные прежние команды сохранены.
